# 변경 제안서: CP-005 저장소 민감 데이터 격리와 회전 절차

## 현재 상태

- 로컬 SQLite 데이터베이스와 Playwright 실행 산출물이 Git에서 추적됩니다.
- 일부 개발·검증 스크립트에 고정 관리자 인증 정보가 남아 있습니다.
- 이 데이터는 이미 원격 Git 이력에 포함되어 있을 수 있어, 새 커밋에서 제거하는 것만으로는 과거 노출을 해소하지 못합니다.

## 즉시 적용 범위

- DB 파일, 테스트 결과, 스크린샷, 임시 검증 산출물을 `.gitignore`에 추가합니다.
- 현재 Git 인덱스에서 이 산출물을 제거하되 로컬 개발 파일은 보존합니다.
- 인증 정보가 고정된 보조 스크립트를 환경 변수 기반 또는 제거 가능한 구조로 전환합니다.

## 별도 승인·권한이 필요한 후속 조치

1. 원격 Git 이력에서 민감 파일을 `git filter-repo` 또는 BFG로 제거하고 force-push합니다.
2. 영향받은 비밀번호, 소셜 토큰, 결제 관련 키를 각 제공자 콘솔에서 회전·무효화합니다.
3. 원격 저장소 접근 로그와 fork/clone 범위를 점검합니다.

## 검증 기준

- `git ls-files`에 로컬 DB·테스트 산출물이 남아 있지 않습니다.
- 새 스크립트는 환경 변수 없이는 동작하지 않으며 비밀값을 출력하지 않습니다.
- Git 이력 정리 전후에 프로젝트를 새로 clone하여 민감 파일이 복원되지 않는지 확인합니다.
